# Site Açaí Ouro Roxo

Site web para uma loja de açaí, desenvolvido com HTML, CSS e JavaScript.

## Conteúdo

- Página inicial;
- Apresentação de produtos e informações da loja;
- Elementos visuais e interações da interface.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abra o arquivo principal do site em um navegador ou use um servidor local.
