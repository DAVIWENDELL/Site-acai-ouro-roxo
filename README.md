# Site-acai-ouro-roxo

Este repositório contém um site para uma loja de açaí, desenvolvido com HTML, CSS e JavaScript.

## Descrição do Projeto

O projeto é um site estático para a marca "Açaí Ouro Roxo", com o objetivo de apresentar produtos, informações de contato e possivelmente um sistema de pedidos ou localização de lojas. A estrutura de arquivos indica uma página principal (`index.html`), estilização (`style.css`), e scripts JavaScript (`index.js`) para interatividade. A pasta `img` contém diversos ícones e imagens relacionadas à marca e funcionalidades como login e redes sociais.

## Funcionalidades

*   Página inicial com informações sobre açaí.
*   Design visual atraente com imagens e ícones.
*   Possíveis funcionalidades de login/cadastro (indicado por `perfil-de-usuario.png`, `email.png`, `cadeado-aberto.png`).
*   Links para redes sociais (indicado por `facebook.png`, `google.png`).

## Tecnologias Utilizadas

*   **HTML5:** Estrutura das páginas web.
*   **CSS3:** Estilização e layout.
*   **JavaScript:** Interatividade no frontend.

## Como Visualizar o Projeto

Para visualizar este projeto localmente, siga os passos abaixo:

1.  **Clone o repositório:**
    ```bash
    git clone https://github.com/DAVIWENDELL/Site-acai-ouro-roxo.git
    cd Site-acai-ouro-roxo
    ```
2.  **Abra o arquivo `index.html`:**
    Simplesmente abra o arquivo `index.html` em seu navegador web preferido. Não é necessário um servidor web para visualizar o site estático.
